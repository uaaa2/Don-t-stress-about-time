# 열람실 타이머 1.2.1

갤럭시 S22 울트라(Android 16)용 열람실 타이머입니다. 헤이영을 열면 입실·재연장·종료를 선택할 수 있고, 기본 3시간 타이머는 종료 15분 전에 알려 줍니다.

[APK 다운로드](https://github.com/uaaa2/Don-t-stress-about-time/raw/refs/heads/main/ReadingRoomTimer-S22Ultra-Android16.apk)

## 설치

1. 휴대폰에서 APK를 내려받고 **내 파일 → 다운로드**에서 열어 설치합니다.
2. 설치 출처를 허용하라는 화면이 나오면 APK를 연 앱에 설치를 허용합니다.

## 실행

1. **열람실 타이머 → 설정**에서 **알림**과 **정확한 알람**을 허용합니다.
2. **접근성 감지 권한 설정 → 설치된 앱 → 열람실 타이머 · 헤이영 감지**를 켭니다.
3. 도서관에서는 휴대폰 위치를 켜고 **정확한 위치**를 **앱 사용 중**으로 허용합니다. 도서관 밖에서 시험하려면 앱 설정의 **도서관 위치 확인**을 끕니다.
4. **타이머 → 감지 시작**을 누른 뒤 헤이영을 엽니다. 알림에서 **시작하기**를 누릅니다.

자동 차단으로 설치가 막히면 **설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단**을 잠시 끄고, 설치 후 다시 켭니다. 접근성 스위치가 막히면 **설정 → 애플리케이션 → 열람실 타이머 → ⋮ → 제한된 설정 허용**을 선택합니다.

Android 16 에뮬레이터에서 설치와 실행을 확인했습니다. S22 울트라 실기기 테스트는 남아 있습니다.
